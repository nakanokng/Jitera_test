# AGENTS.md — このリポジトリでAIエージェントが守るルール

このファイルは、Jitera（VS Code拡張機能）などのAIエージェントがコードを生成・編集するときに参照するルールです。
チームの暗黙知をここに書いておくと、エージェントの出力がチームの書き方に揃います。

## 対象
- .NET Framework 4.8 / C# 7.3（C# 8 以降の構文は使わない：`switch` 式、null 許容参照型、`using` 宣言など）
- Windows Forms

## コーディング規約
- コメント・メッセージは日本語で書く。public メソッドには `/// <summary>` を付ける。
- 金額は必ず `decimal` を使う。端数処理は **切り捨て（Math.Floor）** が社内標準。
- 業務ロジックは `Services/` に置き、Form（画面）には書かない。
- 新しい割引・料金ルールを追加するときは `PriceCalculator` に追加し、既存ルールとの適用順をコメントで明記する。

## テスト
- テストフレームワークは MSTest。テストプロジェクトは `tests/SampleOrderApp.Tests`。
- テストメソッド名は `メソッド名_条件_期待結果` を日本語で書く（例：`Calculate_一般会員_送料あり_標準税率`）。
- 境界値（9個/10個、9,999円/10,000円 など）は必ず両側をテストする。
- 現在時刻に依存する処理は `OrderService` のコンストラクタに `Func<DateTime>` を渡してテストする。
